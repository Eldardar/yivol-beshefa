# פריסה

1. התקינו Node 22 והריצו `npm ci`.
2. הגדירו `DATABASE_PATH` לנתיב מוחלט על אחסון מתמיד והרשאות 0700 לספרייה.
3. גבו את SQLite (כולל WAL/SHM או באמצעות SQLite backup) לפני שינוי גרסה.
4. הריצו `npm run db:migrate`, `npm run build`, ואז `npm start` מאחורי reverse proxy עם HTTPS.
5. הגדירו Health check ל-`/login`; הפעילו תהליך יחיד בעת שימוש במגביל הכניסה המובנה.
6. צרו מנהל עם משתני `SEED_ADMIN_*`, הריצו `npm run seed`, ומחקו אותם מסביבת הריצה.

## שחזור וחזרה
עצרו כתיבות, החזירו את קובץ הגיבוי והגרסה הקודמת, הריצו build והפעילו מחדש. המיגרציות מצטברות; אין לבצע downgrade עיוור.

## אימות
בדקו HTTPS, כותרות, כניסה/יציאה, הפרדת מנהל וקוטף, יצירת טיוטה/פרסום, הופעת הודעה, זמינות ודוח מוביל. ניטור אינו רשאי לרשום סיסמאות, cookies או גוף טפסים.
